# Super Mario Bros. Fun Game HTML

Fan-game de Super Mario Bros feito em HTML5 + Canvas.

**6 fases + Boss final Bowser** (estilo Mario 3 + mecânicas novas).

## Créditos

**Desenvolvedor:** Augusto Miguel de Farias

Isso é uma **fãgame feita por diversão**.

Não afiliado à Nintendo.

## Como jogar

Abra o arquivo `index.html` no navegador (Chrome, Firefox, Edge etc).

### Controles
- **Teclado:** Setas / A-D · Z / Espaço (pulo) · X / Shift (ataque / Fire / Hammer)
- Touch controls e Gamepad também funcionam

### Boss Bowser
Pule **embaixo** das plataformas para virar o Bowser de barriga pra cima, depois pise no casco. Cuidado que ele gira e te fode se você demorar!

## Power-ups
- Cogumelo (Big)
- Flor de Fogo
- Martelo (Modo Construtor)
- Casco

Divirta-se!
